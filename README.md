# 🛍️ Nettenbegen E-ticaret Sitesi

**Beğeneceğiniz Sanal Market** - Kaliteli ürünler, uygun fiyatlar ve hızlı teslimat.

## 🌟 Özellikler

### 🎯 **Tam Yönetimli Admin Panel**
- **Slider Yönetimi**: Dinamik slider içerik yönetimi
- **Kategori Yönetimi**: CRUD işlemleri ile kategori yönetimi
- **İçerik Yönetimi**: WYSIWYG editör ile sayfa içerikleri
- **Gelişmiş Ürün Yönetimi**: Detaylı ürün sistemi
- **Site Ayarları**: Genel site konfigürasyonu
- **Müşteri Yönetimi**: Müşteri veritabanı ve profilleri
- **Sipariş Yönetimi**: Sipariş takibi ve durum yönetimi
- **Raporlar & Analitik**: Satış istatistikleri ve raporlar

### 🎨 **Modern Tasarım**
- **Responsive Design**: Tüm cihazlarda mükemmel görünüm
- **Glassmorphism**: Modern görsel efektler
- **Smooth Animations**: Yumuşak geçişler ve animasyonlar
- **User-Friendly**: Kullanıcı dostu arayüz

### 🛒 **E-ticaret Özellikleri**
- **Ürün Kategorileri**: Organize ürün yapısı
- **Gelişmiş Filtreleme**: Kategori, fiyat, stok durumu filtreleri
- **Arama Sistemi**: Akıllı ürün arama
- **Sepet Sistemi**: Alışveriş sepeti yönetimi
- **Ödeme Sistemi**: Güvenli ödeme altyapısı

## 🚀 Kurulum

1. **Repository'yi klonlayın:**
   ```bash
   git clone https://github.com/ERKAN675/nettenbegen-ecommerce.git
   cd nettenbegen-ecommerce
   ```

2. **Dosyaları web sunucusuna yükleyin:**
   - Tüm dosyaları web sunucunuzun root dizinine kopyalayın
   - Veya localhost'ta çalıştırmak için bir web server kullanın

3. **Admin paneline erişim:**
   - `admin.html` dosyasını tarayıcınızda açın
   - Tam yönetimli admin paneli kullanmaya başlayın
